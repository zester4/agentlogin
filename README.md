# agentlogin

Startup enabling AI agents to securely log in to websites and perform actions on behalf of users (with approval).

## Focus
- Secure credential vault and site-compatible login flows
- Agent actions: booking, ordering, reservations, account management
- Early targets: travel (Booking.com, Airbnb), rides (Uber, Lyft), food (Uber Eats, DoorDash), flights

## Status
Building. Prioritizing safe delegation over broad automation.

Sites differ in CAPTCHA, 2FA, bot detection. Compatibility statuses: Supported / Limited / User-only / Blocked.
